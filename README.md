# Burcu Özberk

Giochi con le foto di Burcu Özberk: **Memory** (con la caccia al tesoro), **Ultima carta** e **Puzzle**. In italiano e in turco.

Gioca qui: https://napoli1984.github.io/Burcuozberk/

Per Memory e Ultima carta si può scegliere tra sei **modelli di carte** (Velluto, Polaroid, Cipria, Notte, Nazar e Oro, il premio della caccia al tesoro).

Memory e Ultima carta si possono giocare anche **online con gli amici** (da 2 a 4, ognuno sul suo telefono): chi crea la stanza manda il link agli altri. I messaggi passano da un servizio MQTT pubblico e gratuito.

Caratteri: Cormorant Garamond e Manrope, con licenza SIL Open Font License (i testi delle licenze sono nella cartella `fonts`).

Fan game senza scopo di lucro: le foto appartengono ai rispettivi autori.
